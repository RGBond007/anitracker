# Support

## Usage and installation help

Start with the [installation and troubleshooting guide](INSTALL.md). If the problem remains,
search existing GitHub issues before opening a new one.

When requesting help, include:

- AniTracker version or commit
- Installation method and operating system
- Docker and Docker Compose versions
- Relevant configuration with secrets removed
- Exact error messages and minimal reproduction steps

Do not post `.env` files, passwords, session cookies, JWT secrets, database exports, or private
user data.

## Bugs and feature requests

Use the repository's issue forms. Bug reports should describe reproducible behavior. Feature
requests should begin with the user problem and desired outcome rather than only a proposed
implementation.

## Security

Do not use public support channels for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

Support is community-provided on a best-effort basis; response times are not guaranteed.
